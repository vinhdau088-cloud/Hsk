# Chinese & TOCFL Learning App

Ứng dụng web Học Tiếng Trung & TOCFL đầy đủ các trang và thành phần chuẩn thiết kế gradient tím-hồng, nút vàng, card trắng bo góc.

## 📁 Danh sách 7 Trang:
1. `index.html` - Trang chủ
2. `hsk.html` - Trang HSK (Có đủ 6 thẻ HSK 1 - HSK 6)
3. `tocfl.html` - Trang TOCFL (Có đủ 4 thẻ A1, A2, B1, B2)
4. `dictionary.html` - Trang Từ điển
5. `exam.html` - Trang Luyện thi
6. `profile.html` - Trang Hồ sơ
7. `login.html` - Trang Đăng nhập

## 🚀 Hướng dẫn Upload GitHub & Vercel:
1. Giải nén file `.zip`.
2. Tạo Repository mới trên GitHub và tải toàn bộ các file trong thư mục lên.
3. Import Repo từ GitHub vào Vercel và bấm Deploy!
